**Pancreatic multiome models: short assessment and next steps**

This incorporates the follow-up clarifications: accessibility attenuation is intended to approximate CRISPRi; the screen is unpublished and being developed with the collaborating lab; missing bigWigs will be recovered; and DragoNNFruit, not Scooby, has been tested on these data. The initial work targets pseudobulks and does not require Scooby. Scooby remains a possible later comparison. The original [full assessment](panc_multiome_modeling_assessment_2026-09-04.md) is preserved as the earlier audit; this note supersedes its assumptions about the screen and prior Scooby work. Historical script/config discrepancies are set aside for planning.

**Recommendation:** proceed with RNA BAM processing and start training on one cell state. Use this pilot to validate the data and compare count-only versus count+profile supervision before expanding to a shared multi-state model. One state is sufficient for this initial check, but cannot establish improved cell-state specificity or transfer.

| Potential issue | Decision / next step |
|---|---|
| CRISPRi simulation | The collaborator's unpublished screen is understood to use CRISPRi/Perturb-seq; confirm the assay details and label definitions with them. Accessibility attenuation is a reasonable operational approximation to benchmark. Fix attenuation strength/flanks using development data. For the low-UMI screen, distinguish supported nonhits from underpowered pairs rather than labeling every nonsignificant pair negative. |
| State and sample association | State-level pseudobulks are acceptable for a first study of these sampled states. Preserve sample provenance and match the RNA/ATAC mixture. Results do not establish transfer across donors, protocols, or independent differentiations. If testing an unseen state, exclude all of its RNA labels from training/model selection; use a separate genomic holdout to test unseen genes. |
| Small populations | Keep them initially. Late Delta has 244 cells: split-half expression r=0.946, but cell-type-specific residual r=0.687. This suggests less reproducible differential signal, not unusable pseudobulk or excessive biological distinctness. Repeat split-half checks and compare larger populations downsampled to 244 cells. |
| Genomic overlap | Not a blocker for the initial pilot; fix when the pancreatic splits are built, not by retrofitting K562. In the inspected K562 split, 7.9% of test windows overlap training windows, 3.8% of test TSSs lie inside one, and 4.03% of test nucleotides are shared with training territory. The bounded worst case on gene-level metrics is +0.016 Pearson r, below seed variation, and affected genes skew toward the non-expressed tail. The pancreatic work needs a new gene-info JSON and new splits anyway, so buffer in the builder there. Whole-window RNA supervision still exposes held-out RNA labels, and that leakage is asymmetric between the count-only and count+profile arms, so treat their delta as a pipeline check rather than a result until the splits are clean. Use buffered genomic blocks or chromosome splits, including sequence jitter. |
| Accessibility scale | Recover all tracks, confirm fragment/barcode processing, and normalize consistently. Available tracks span 29-fold in total signal and differ in scale from the pretrained DNase input. Include depth-rescaling and cell-state-swap controls. |
| RNA profiles | Generate matched, stranded, UMI-aware coverage from the unperturbed RNA BAMs, preserving sample identity. Validate barcode membership, strand, intron handling, and consistency with gene counts; integrated read-base coverage need not equal UMI counts. Do not infer profiles from the h5ad matrix or mix perturbed cells into the unperturbed training targets. |
| Fair comparisons | Compare count-only, count+profile, and profile-only models with the same windows, masks, splits, and ATAC. Include a trained sequence-only counterpart, simple ATAC/distance E2G controls, and the planned external models. Audit the reported weak AlphaGenome result for track/state matching, context eligibility, and scoring before treating it as established. |

Lower residual reproducibility reflects the ratio of reproducible state-specific signal to noise. Limited cell number, within-state heterogeneity, and a weak differential component can all contribute. The existing check cannot distinguish these causes. A genuinely distinct but consistently sampled population can score well: DE has residual split-half r=0.987. No RNA base-resolution profile reproducibility was tested, and it may be lower than gene-count reproducibility.

For prior models, first re-evaluate expression on the clean nonoverlapping subset, with distance/expression distributions reported, rather than assuming every result needs discarding. Perturbation testing at loci whose unperturbed RNA was used in training remains a meaningful task if perturbation outcomes were held out; describe it as unseen perturbations at familiar loci. This differs from claiming unseen-locus generalization. Final new-model comparisons should use clean, shared splits.

**Suggested order of work**

1. Establish the reference and run provenance from the RNA BAM headers. The `@CO user_command_line` line names the Cell Ranger transcriptome, `@PG ... VN:` gives the version that determines the default intron behaviour, `@SQ` confirms the assembly and contig set, and the first read's tags confirm `CB`/`UB` are present for UMI-aware coverage. Record the gencode version from the reference's `reference.json`. This one step fixes the gene universe, the TSS geometry, and the gene assignment used for coverage, so it precedes everything else. In parallel and asynchronously, ask the collaborating lab for the missing tracks, sample sheet, screen metadata and label definitions, any development/test partition, and the existing DragoNNFruit evaluation details.
2. Build the gene universe and the pseudobulked gene counts, and decide which cell types and time points to carry forward. Map symbols to stable Ensembl IDs against the quantification GTF and join on the versionless ID thereafter. Retain a gene if it clears roughly 10 CPM in at least one state, with a small minimum cell count in that state, so that state-restricted genes in the smaller and most distinct populations survive; a global cells-detecting threshold must not be used, since it deletes real markers. Pseudobulk raw UMIs by state with biological sample provenance preserved, then normalize once. Fix the genomic splits at the same time, buffered on full input windows including jitter, and define ATAC normalization, gene-count targets, and the CRISPRi score. Check that enhancer-screen genes are retained and their candidate elements fit the input windows.
3. Reprocess the RNA BAMs into stranded, UMI-aware coverage for the chosen state, matching the options the quantification actually used, intron inclusion in particular. Where the profile target is deliberately allowed to differ from the counts, say so explicitly rather than discovering it as a discrepancy. Prioritize the screen-matched state when coverage is adequate; if that state is particularly sparse, use a well-sampled state for a technical pipeline check first, which does not replace the screen-matched evaluation. Check both strands, zero background, chromosome alignment, gene-level consistency against the matrix, and split-half profiles in covered regions. Keep untransformed coverage available for later binning/normalization choices.
4. Train a matched pair: pretrained sequence+ATAC count-only and count+profile models, with identical windows, masks, splits, and count targets. Check held-out expression and profile behavior. Use a predeclared development subset for E2G comparison if available. Add profile-only as a third model if feasible; a rate-profile head predicts magnitude, while a multinomial-only head needs a relative-shape scoring definition. Repeat promising comparisons across seeds before treating a small gain as reliable.
5. Once the pipeline is sound, add a second contrasting state and test whether predictions respond appropriately to its ATAC. Then train a shared model across the available states. There is no need to train a separate model for every state first. Introduce sequence-only/no-pretraining controls and external baselines as the setup stabilizes.
6. Run specificity, reduced-cell/label, and held-out-state experiments, then the final held-out screen comparison. Keep final screen results out of loss-weight, checkpoint, and attenuation tuning. If no screen development subset is available, choose settings using expression/profile validation and prior independent benchmarks.

The immediate work is data preparation, clean splits, and the one-state count/profile comparison. Scooby is optional later and should not delay this pilot. The prior E2G gains motivate profile supervision without guaranteeing the same benefit here. Well-powered negatives and direct versus indirect perturbation effects matter for the final labels. [scE2G benchmarking paper](https://www.nature.com/articles/s41588-026-02695-8).
